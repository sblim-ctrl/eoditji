# 사용자 테스트 안내문과 설문 (D4-7)

- 방식: 온라인, 각자 휴대폰으로 20분. 설문은 구글 폼, 이메일은 받지 않는다.
- 확인할 것: PRD 03 가정 1(정리하는 날 사진으로 기록해 줄 것이다). 수치(기록 완료율, 1칸 기록 시간, 찾기 결과)는 `events`로 집계하고(8번), 설문은 이유를 듣는 데 쓴다.
- 테스트 중에는 배포하지 않는다. 설문 원본 응답은 저장소에 올리지 않는다.

## 보낼 안내문

> 안녕하세요! 집에 둔 물건을 사진으로 기억해 두고, 나중에 "○○ 어디 있지?" 하고 물으면 찾아 주는 앱 **어디있지?**를 만들고 있어요. 20분 정도 써 보고 설문에 답해 주시면 큰 도움이 됩니다.
>
> **주소**: https://eoditji.vercel.app (휴대폰에서 열어 주세요)
>
> **해 볼 것**
> 1. 구글 계정이나 이메일 코드로 로그인해요. 첫 화면에서 대화 상대(엄마 / AI 비서)를 골라요.
> 2. 집에 있는 서랍이나 수납장 **1~2칸**을 위에서 찍어 올려요.
>    - AI가 찾은 물건 목록을 보고, 틀린 이름은 고치고 빠진 물건은 더해 주세요.
>    - 칸 이름과 공간(예: 책상)을 알려 주면 저장돼요.
> 3. 방금 기록한 물건을 **3번 이상** 찾아봐요.
>    - 기록된 이름과 다르게도 물어보세요. (예: "보조배터리" 대신 "충전기 어디 있어?")
>    - 기록하지 않은 물건도 한 번 물어보세요.
> 4. 답이 나오면 **찾았어!** 또는 **거기 없던데?**를 눌러 주세요.
> 5. 끝나면 설문에 답해 주세요: (구글 폼 링크)
>
> **알아 두실 것**
> - 사진과 질문은 물건 목록을 만들고 찾는 데만 쓰여요. OpenAI로 보내져 미국에서 처리되고, 학습에는 쓰이지 않아요.
> - 화장대·욕실·서류함처럼 남에게 보이기 싫은 칸은 피해 주세요.
> - 끝난 뒤 기억해 둔 곳에서 칸을 지우면 사진도 함께 지워져요.

## 설문 문항 (구글 폼)

| # | 문항 | 형식 | 보기 |
|---|---|---|---|
| 1 | 지금 어떻게 살고 계세요? | 객관식 | 혼자 산다 / 가족과 산다 / 친구·연인과 산다 / 기타 |
| 2 | 몇 칸을 기록하셨나요? | 객관식 | 0칸(못 했어요) / 1칸 / 2칸 / 3칸 이상 |
| 3 | 한 칸을 기록하는 데 걸린 시간은 어떻게 느껴졌나요? | 객관식 | 1분 안 / 1~2분 / 2~5분 / 5분 넘게 |
| 4 | AI가 찾은 물건 목록은 얼마나 맞았나요? | 1~5점 | 1 거의 틀림 ~ 5 거의 다 맞음 |
| 5 | 칸 이름을 먼저 묻고 공간(방·가구)을 나중에 묻는 순서는 어땠나요? | 객관식 | 자연스러웠다 / 공간을 먼저 묻는 게 낫겠다 / 잘 모르겠다 |
| 6 | 찾기 결과를 믿고 그 칸을 열어 볼 마음이 들었나요? | 1~5점 | 1 전혀 ~ 5 바로 열어 볼 것 같다 |
| 7 | 찾지 못했거나 엉뚱한 답이 나온 질문이 있었다면 적어 주세요. | 주관식 (선택) | |
| 8 | 어떤 대화 상대를 쓰셨고, 말투는 어땠나요? | 객관식 + 기타 | 엄마, 좋았다 / 엄마, 어색했다 / AI 비서, 좋았다 / AI 비서, 어색했다 |
| 9 | 가장 막히거나 헷갈린 곳은 어디였나요? | 주관식 | |
| 10 | 다음에 옷장이나 서랍을 정리하는 날, 이 앱으로 기록해 둘 것 같나요? | 1~5점 | 1 전혀 ~ 5 꼭 쓸 것 같다 |
| 11 | 10번에서 그렇게 답한 이유는 무엇인가요? | 주관식 | |
| 12 | 하나만 고친다면 무엇을 고치고 싶나요? | 주관식 | |

- 폼 설정: 이메일 수집 끄기, 로그인 필요 끄기. 1~6, 8~10번은 필수.
- 응답을 계정과 맞추지 않는다. 행동 수치는 `events`에서 테스터 전체로 본다.
